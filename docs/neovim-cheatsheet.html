Neovim チートシート

コマンド一覧ではなく、「今から何をしたいか」で引くためのガイド。 基本のVim操作と、このdotfilesで追加した開発機能を一緒にまとめています。

Situation

まず迷わない 目的地へ移動する 文章・コードを編集する 探す・置換する ファイルと画面を扱う プロジェクトを探す コードを理解・修正する 変更内容を確認する テストを実行する デバッグする 困ったとき
一致する操作がありません。
01

まず迷わない

モードを意識する

基本

Vimは同じキーでもモードによって動作が変わります。迷ったらまずNormalモードへ戻ります。

EscNormalモードへ戻る。この設定では検索ハイライトも消す
iInsertモードへ入り、カーソル位置から入力する
vVisualモードで文字単位の選択を始める
:コマンドラインを開く
SpaceLeader。少し待つとwhich-keyが機能一覧を表示する

保存して終了する

Command
:w現在のファイルを保存する
:q現在のウィンドウを閉じる
:wq / ZZ保存して閉じる
:q!変更を破棄して閉じる
:wa変更済みの全ファイルを保存する
:qaNeovimを終了する
confirmが有効なので、未保存の変更がある操作では確認が表示されます。

このページの読み方

Notation
Spaceff順番に押す。Leader表記なら<Leader>ff
Ctrl+d<C-d>。Ctrlを押しながらdを押す
d{motion}{motion}にはwや$などの移動を入れる
3j数字は回数。3行下へ移動する
大文字・小文字は別の操作です。uとU、pとPは区別します。

「操作 × 範囲」で編集する

Vimの核

d削除、c変更、yコピーに、移動やテキストオブジェクトを続けます。

iはinside（内側だけ）、aはaround（囲みや空白も含む）。例: diw と daw。

現在の設定で自動になること

Config
  • 行番号、現在行、sign columnを常時表示
  • タブは»、行末の余分な空白は•で可視化
  • インデントは基本2スペース、Tab入力もスペースへ展開
  • コピー・削除・貼り付けはシステムクリップボードと共有
  • yank直後の範囲を一時的に強調
  • Ruby / Rust / JavaScript / TypeScriptはLSP、補完、保存時フォーマットが有効
  • Tree-sitterによる構文解析、indent guide、Git差分表示が自動で有効
